# Asmaa
Angelegt über das BRAFO-Dashboard

## Seiten
- `index.html` – Kosmetik-Quiz (10 Fragen)
- `abenteuer.html` – Inselabenteuer mit Luffy und Zoro (2D, 6 Inseln, Münzen sammeln)
- `welt3d.html` – 3D-Insel zum freien Erkunden (three.js liegt unter `lib/`)
- `schiessstand.html` – 3D-Schießstand: vier Waffen auf dem Tisch (C96 Mauser, Double-Action-Revolver, G36, KR86), zwölf Zielscheiben rundherum, unendlich Munition. Maus = drehen, Rechtsklick = zielen, Linksklick = schießen, E = Waffe nehmen. Kopftreffer werfen eine Scheibe sofort um, Körpertreffer nach 6 Schüssen.
- `shop.html` – Fan-Shop zum Spiel (Produkte, Warenkorb, Kasse im Vorschau-Modus ohne echte Zahlung)
